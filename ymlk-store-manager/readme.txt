A simple, fast store-management app for WooCommerce shop owners.

== Description ==
Overview of sales, orders with one-tap status changes and WhatsApp contact, products with an easy sizes/colours builder, and stock control, in one mobile-friendly screen inside WordPress.

Developed by YMLK Technologies — https://ymlktechnologies.com
